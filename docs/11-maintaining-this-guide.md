# 11 · Maintaining this guide

If you change something in the codebase that a future intern would trip over — a renamed field, a new env var, a different folder, a removed endpoint, a shifted convention — update this guide in the same PR. Same rule for [`../CLAUDE.md`](../CLAUDE.md): if the change makes a line in CLAUDE.md untrue, fix that line in the same commit. Stale docs are worse than no docs because they actively mislead. Reviewers should treat a doc-impacting change without a doc update as an incomplete PR.
